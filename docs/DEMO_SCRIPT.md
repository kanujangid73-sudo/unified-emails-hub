# Two-minute demo video

A walkthrough to record for the README, LinkedIn or a job application. Record the browser at
1440×900 with a screen recorder (Windows: **Win + Alt + R** in the Xbox Game Bar, or the free
[OBS Studio](https://obsproject.com)). Warm the API up first by opening `/api/health`, so the
demo starts instantly.

| Time | Show | Say |
|---|---|---|
| 0:00 | Sign-in page | "This is Unified Emails Hub: one inbox for all my email accounts, Gmail, Outlook and any IMAP mailbox. I'll use the one-click demo." |
| 0:10 | Click **Try the demo** | "It creates three sample mailboxes and syncs them through the same engine real accounts use." |
| 0:20 | Inbox; point at the coloured bars and the **Primary / Updates / Promotions / Newsletters** tabs | "Every account in one list, colour-coded, and sorted into tabs automatically." |
| 0:35 | Open the **PayWave** email | "This one is flagged as phishing, and it says why: a look-alike domain, pressure tactics and an unencrypted link. That runs on the server, so no email leaves it." |
| 0:50 | Press **Summarize** | "On request, Gemini summarises a conversation. The email is passed as untrusted data, so a message can't give the AI instructions." |
| 1:00 | Open **Cricket this Saturday?** → Reply → type "yes, I'll bring the bats" → **Draft reply** | "And it drafts replies I can edit before sending." |
| 1:15 | Open **Photos from the trek**, download a photo | "Attachments are fetched from the provider only when downloaded, never stored." |
| 1:25 | **Account Finder** | "My favourite feature: it finds every website I've signed up to, and with which address. ShopKart has two of my addresses; the fake PayWave email doesn't count." |
| 1:40 | Search `from:priya is:starred` | "Gmail-style search, on Postgres full-text search." |
| 1:50 | GitHub repo: README, CI badge, `docs/DECISIONS.md` | "Behind it: incremental sync with leases and backoff, encrypted credentials, about 140 tests on SQLite and Postgres, and every design decision written down." |

Tips: hide the bookmarks bar, zoom the browser to 110%, and keep the mouse still while talking.
Add captions; most people watch muted.
